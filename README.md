# 👔 Royal Fashion Store (Capstone Project)

A complete, production-ready frontend web application built as a Full Stack Web Development Capstone Project for RabTech Academy.

## ✨ Key Features
- **Authentication Simulation:** Seamless user login and session management using `localStorage`.
- **Interactive Catalog:** Displays 12+ default clothing items (Shirts, Pants, Coats, Jodhpuri, T-Shirts, etc.) with real product images.
- **Full Dynamic CRUD Operations:**
  - **Create:** Add new custom fashion products with name, price, category, and image URL.
  - **Read:** Real-time product rendering and instant live search filtering.
  - **Update:** Edit existing product details seamlessly.
  - **Delete:** Remove unwanted items from the catalog.
- **Persistent State:** All products, cart items, and user sessions persist across browser refreshes via `localStorage`.

## 🛠️ Tech Stack
- **HTML5** (Semantic Structure)
- **CSS3** (Modern Flexbox/Grid, Gradients, Responsive UI)
- **JavaScript (ES6+)** (DOM Manipulation, State Management, LocalStorage)
